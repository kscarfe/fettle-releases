# Fettle

A World of Warcraft Forever addon for managing alts: per-alt consumable kits,
a pre-dungeon checklist, wish lists, and bank, mailbox and vendor hints.

## Install (Windows, updates itself, no GitHub account)

1. Close WoW.
2. Download **Install Fettle.cmd** from this page (click it, then the download button) and double-click it.
   If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
3. Follow the prompts. Fettle is installed and checks for updates every 15 minutes and
   when you sign in to Windows. When an update arrives you get a notification: type `/reload` in WoW.

To check for an update right away, double-click **Update Fettle** on your desktop.
To stop automatic updates, run `tools\guild\Uninstall Fettle updater.cmd` from the Fettle folder.

In game: `/fettle` or `/fet`.
